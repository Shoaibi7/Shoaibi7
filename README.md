## 🚀 What I'm Building

### 🔎 HireSignal

**Evidence-backed candidate screening for better hiring decisions.**

HireSignal is an applicant tracking and candidate-screening platform designed around a simple principle:

> **AI surfaces the evidence. Humans make the hiring decision.**

It analyzes candidate information from CVs, screening answers, and public technical evidence, then provides explained recommendations for recruiters.

**Built with:**
`Python` `FastAPI` `PostgreSQL` `Redis` `ARQ` `React` `TypeScript` `OpenRouter` `S3`

**Engineering highlights:**
- Evidence-based Gate → Align screening pipeline
- Human-in-the-loop decision making
- Background worker retries and recovery
- Private CV storage
- Candidate data lifecycle and retention controls
- Rate limiting and public endpoint protection
- Screening regression benchmark

### 🧠 RAG Knowledge Assistant

A lightweight Retrieval-Augmented Generation project for answering questions from a private knowledge base.

**Pipeline:**

`Documents → Chunking → Embeddings → Vector Search → Context → LLM Answer`

Built using:

`Python` `LangChain` `Chroma` `BGE Embeddings` `Ollama` `FastAPI`

The system loads PDF/TXT/MD documents, stores their embeddings locally, retrieves relevant context for a query, and generates answers grounded in the retrieved knowledge.
